# Jharshini's Boston Homepage

A personal homepage about my hobbies and the parts of Boston I love most: an About Me page, a guide to my favorite coffee shops, and a handful of favorite spots around the city.

## Project Objective

Build a multi-page personal website with HTML, CSS, and JavaScript (ES6 modules, no libraries) that lets visitors get to know me through my interests. The site has three pages:

| Page | What it does |
| --- | --- |
| **About Me** (`index.html`) | A short intro, photo, and my hobbies and interests. |
| **Boston Coffee Shops** (`coffee.html`) | Cafés rated on coffee, atmosphere, and work/study-friendliness. Ratings show as teacup icons, and visitors can sort the list by any of the three ratings. |
| **Boston Spots** (`spots.html`) | Favorite places around the city, each with a photo and suggestions for what to do there. Visitors can filter by neighborhood. |

Both the coffee and spots pages have a sticky sidebar that jumps to each entry and highlights the one currently in view.

## Instructions to Build

The pages use ES6 modules, which browsers block when a file is opened directly from disk (`file://`). Serve the site from a local server instead.

1. Install [Node.js](https://nodejs.org/) if you don't already have it.
2. Clone the repository and move into it:
    ```bash
    git clone [repo URL]
    cd [repo folder]
    ```
3. Install the dev dependencies (Prettier and ESLint):
    ```bash
    npm install
    ```
4. Start a local server:
    ```bash
    npx serve
    ```
5. Open the URL it prints (usually `http://localhost:3000`) in your browser.

To check formatting and linting:

```bash
npx prettier --check .
npx eslint .
```

## Use of Generative AI

The Boston Spots page (`spots.html`), its script (`js/spots.js`), and its CSS additions to `style.css` were generated by **Claude Opus 5.5** (Anthropic) in claude.ai. The place descriptions were researched by the model. All generated code was then checked with Prettier, ESLint, and the W3C validator.

Images on the Boston Coffee Shops pages are AI-generated illustrations using the same model. This was done because no pictures of the coffee shops were available online under CC license and I do not have pictures of my own. The pictures on the Boston spots page were taken by me. 

Both the favicon and the teacup icons used in the ratings of the coffee shops were also generated using Claude Opus 5.5
